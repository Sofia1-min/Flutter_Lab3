## Запуск
1. Клонировать репозиторий
2. Перейти в папку проекта
3. Выполнить `flutter pub get`
4. Запустить `flutter run -d chrome`

## Что изучили

- Виджеты: MaterialApp, Scaffold, Container, Center, Text
- Hot Reload и Hot Restart
